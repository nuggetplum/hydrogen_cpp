Hydrogen Build and Run Commands
===============================

This file documents the commands used to build and run the Hydrogen program.
Run the commands from the project root:

    /home/nuggetplum/compiler/hydrogen

The project root is the directory containing CMakeLists.txt, test.hy, and src/.


Prerequisites
-------------

1. A Linux shell, such as bash.
2. A C++ compiler with C++20 support. The commands below use g++.
3. CMake version 3.28.3 or newer, because CMakeLists.txt requests that minimum
   version.
4. A source input file. The included example is test.hy.
5. Permission to create files in the project directory and a build/ directory.

Check the required tools with:

    g++ --version
    cmake --version

These commands only display the installed versions. They do not build or modify
anything.


Command 1: Direct compilation used for diagnosis
--------------------------------------------------

    g++ -std=c++17 src/main.cpp -o hydro

What it does:
- Starts the GNU C++ compiler.
- Uses the C++17 language standard with -std=c++17.
- Compiles src/main.cpp and the header files included by it.
- Writes an executable named hydro in the project root because of -o hydro.

Prerequisites:
- g++ must be installed and available on PATH.
- src/main.cpp and src/tokenization.hpp must exist.
- The command must be run from the project root, because it uses the relative
  path src/main.cpp.

Result:
- This was a diagnostic command and failed before the source fixes were made.
- It reported missing standard headers, a malformed Tokenizer constructor, and
  duplicate tokenizer declarations.
- A failed compilation does not create a usable executable.


Command 2: Direct compilation after the source fixes
------------------------------------------------------

    g++ -std=c++20 src/main.cpp -o hydro

What it does:
- Compiles the program using the C++20 language standard.
- Produces a standalone executable named hydro in the project root.
- Does not create a build directory or use CMake.

Prerequisites:
- g++ with C++20 support must be installed.
- The command must be run from the project root.
- The source files must compile successfully.

Result:
- This command completed successfully after the source fixes.
- The resulting executable is ./hydro.


Command 3: Run the directly compiled executable
------------------------------------------------

    ./hydro test.hy

What it does:
- ./hydro starts the executable in the current directory.
- test.hy is passed as the program's first command-line argument.
- The program opens test.hy, tokenizes the return statement, and exits with
    the integer value in that statement.

Prerequisites:
- Command 2 must have completed successfully, so ./hydro exists.
- test.hy must exist in the current directory and be readable.
- The program requires exactly one input-file argument.

The program itself prints no output for a valid return statement. Its process
exit status is 69, which can be displayed with:

    echo $?

Expected output:

    69


Command 4: Configure the CMake build
-------------------------------------

    cmake -S . -B build

What it does:
- Starts CMake.
- -S . tells CMake that the source directory is the current directory.
- -B build tells CMake to place generated build files in build/.
- Reads CMakeLists.txt and generates build-system files for the project.

Prerequisites:
- CMake 3.28.3 or newer must be installed.
- A C++ compiler must be installed.
- The command must be run from the project root.
- CMakeLists.txt must exist in the current directory.

Result:
- Creates build/ if it does not exist.
- Generates the files needed to compile the project.
- This command configures the project but does not necessarily compile the
  executable yet.


Command 5: Build through CMake
-------------------------------

    cmake --build build

What it does:
- Uses the build files generated by Command 4.
- Compiles src/main.cpp according to the settings in CMakeLists.txt.
- Links the object files into the executable target named hydro.

Prerequisites:
- Command 4 must have completed successfully.
- The build/ directory must contain a valid configured CMake build.
- The source files must compile successfully.

Result:
- Creates the executable at build/hydro.
- A successful build ends with a message similar to:

    [100%] Built target hydro


Command 6: Run the CMake-built executable
------------------------------------------

    ./build/hydro test.hy

What it does:
- Starts the executable produced by Command 5.
- Passes test.hy as the input file.
- Tokenizes the return statement in test.hy.
- Exits with the integer value from the return statement.

Prerequisites:
- Command 5 must have completed successfully.
- build/hydro must exist and be executable.
- test.hy must exist in the project root and be readable.

The program itself prints no output. To display its exit status, run:

    echo $?

Expected output:

    69


Recommended workflow
--------------------

For normal development, use these commands from the project root:

    cmake -S . -B build
    cmake --build build
    ./build/hydro test.hy
    echo $?

After the first configuration, the shorter rebuild workflow usually works:

    cmake --build build
    ./build/hydro test.hy
    echo $?

If CMake configuration files become stale or the build directory is damaged,
run the full configuration command again:

    cmake -S . -B build


Common mistakes
---------------

- Do not compile tokenization.hpp as the executable. It is a header file and is
  included by src/main.cpp. Build src/main.cpp or use CMake instead.
- If you see "Incorrect usage", provide exactly one input filename, for example:

    ./build/hydro test.hy

- If you see that test.hy cannot be opened, check your current directory with:

    pwd

  Then either return to the project root or provide the correct path to the
  input file.
- If g++ or cmake is not found, install the compiler and CMake using the package
  manager for your Linux distribution, then rerun the version checks above.
